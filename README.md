# Physical Modeling Intuition

This repository contains a six-month scientific modeling curriculum designed to build reflexive physical intuition through a repeated loop:

**estimate → derive → predict → code → test → interpret → connect to experiment**

## Curriculum checklist

- [ ] Dimensional analysis
- [ ] Characteristic scales
- [ ] Conservation laws
- [ ] Exponential decay
- [ ] Competing rates
- [ ] Coupled rate equations
- [ ] Nonlinear response
- [ ] Diffusion
- [ ] Drift and mobility
- [ ] Equilibrium vs. kinetics
- [ ] Probability
- [ ] Noise
- [ ] Bayesian reasoning
- [ ] Eigenvalues and eigenvectors
- [ ] Fourier transforms
- [ ] Feedback and stability
- [ ] Optimization
- [ ] Gaussian processes
- [ ] Bayesian optimization

## Quantum mechanics for the Klimov review

Start with [Foundations and Section 2.1](klimov_section2/README.md): two guided Google Colab notebooks for learning the quantum mechanics behind semiconductor quantum dots from little or no QM background. They include interactive experiments, worked examples, feedback, and independent reasoning challenges.

- [Open the foundations in Colab](https://colab.research.google.com/github/Shlok-Joseph-Paul/physical-modeling-intuition/blob/main/klimov_section2/01_foundations.ipynb)
- [Open the spherical quantum box (§2.1) in Colab](https://colab.research.google.com/github/Shlok-Joseph-Paul/physical-modeling-intuition/blob/main/klimov_section2/02_spherical_quantum_box.ipynb)

## Repository structure

- `fundamentals/` — core physical reasoning and modeling habits
- `probability_and_inference/` — uncertainty, noise, and inference
- `math_tools/` — reusable mathematical methods
- `optimization_and_ai/` — optimization and data-efficient modeling
- `real_problems/` — integrated applications tied to experiments
- `klimov_reasoning_log.md` — a running record of reasoning, predictions, and lessons
